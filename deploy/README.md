# Публичная демонстрация

Отдельный Compose-проект `manufacturing-demo` использует свой том PostgreSQL и учебные данные. Только nginx публикует порт; БД и Python доступны внутри сети Docker. Доступ приложения к данным — только чтение.

После проверки свободного порта и установленного Docker Compose на сервере:

```sh
sh deploy/prepare-env.sh
docker compose --env-file .env.demo -f compose.demo.yaml up -d --build
```

Пароли создаются на сервере, `.env.demo` не включается в репозиторий или архив. Не заменяйте его пароли после создания тома без отдельного изменения ролей PostgreSQL. Повторный запуск сохраняет данные.

По умолчанию сайт доступен по HTTP на порту 80. Если этот порт занят существующим прокси, выберите свободный порт в `.env.demo` и задайте `DEMO_BIND_ADDRESS=127.0.0.1`, затем подключите существующий прокси. Домен и HTTPS настраиваются после проверки DNS и инфраструктуры сервера.

Проверки: `/api/dashboard?date=2026-09-12`, `/api/health`, три языка и разделы `#sales`, `#orders`, `#supply`, `#health`.

Остановка без удаления данных:

```sh
docker compose --env-file .env.demo -f compose.demo.yaml down
```
