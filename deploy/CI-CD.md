# CI / CD

Workflow `.github/workflows/ci-cd.yml` запускается для pull request и push в `main`. Проверки: новая PostgreSQL с синтетическими данными, интеграционные тесты API/пула, синтаксис JS и shell, сборка Docker и HTTP smoke test.

После успешных проверок push в `main` обновляет публичное демо. Ручной запуск workflow без флага `deploy` выполняет только проверки. Публикация сериализована, выполняется только из `main` и использует проверенный commit SHA.

Настройки репозитория:

- Actions secret `DEPLOY_SSH_KEY`: отдельный ключ публикации, не интерактивный ключ администратора.
- Actions secret `DEPLOY_KNOWN_HOSTS`: проверенный публичный ключ SSH-хоста.
- Actions variable `DEPLOY_HOST`: адрес сервера.
- Actions variable `DEPLOY_ENABLED`: `true` включает CD; без этого значения выполняется только CI.

Публичный ключ CI на сервере ограничен `restrict` и фиксированной командой `/usr/local/sbin/manufacturing-demo-deploy`. У ключа нет интерактивной оболочки, туннелей или произвольных SSH-команд. Получатель принимает только `deploy <40-символьный SHA>` и ограниченный архив исходников приложения: без `.env`, Compose, SQL-инициализации БД и серверных скриптов. Конфигурация сервера и секреты сохраняются отдельно. Изменения серверной конфигурации и схемы данных выполняются оператором, не этим CD.

Получатель собирает образ с тегом SHA, переключает только контейнер приложения, проверяет здоровье и отчёт. При ошибке проверки возвращает прежний образ; данные PostgreSQL не откатываются. CI-код строит приложение, поэтому право изменять workflow или `main` следует выдавать только тем, кто вправе публиковать приложение.

Исходник получателя: `deploy/receive.py`. Установка/обновление выполняется администратором отдельно, через `install -m 755 deploy/receive.py /usr/local/sbin/manufacturing-demo-deploy`.

После CI/CD ручные команды Compose на сервере должны включать `-f compose.release.json`, чтобы использовать опубликованный образ. Текущая ревизия записана в `/opt/manufacturing-demo/.deployed-revision` и в метке Docker-образа `org.opencontainers.image.revision`.
